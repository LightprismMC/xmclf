XMCLF

Offline and Ely.by accounts, never gated.

X Minecraft Launcher Freedoom is a fork of X Minecraft Launcher. It keeps everything the original does well — instances across Forge, Fabric, Quilt and NeoForge, mods and modpacks from CurseForge and Modrinth, managed Java — and takes the locks off the account screen.

What is different

Five changes, all of them about accounts.

The rest of the launcher is upstream code, untouched. These are the reasons this fork exists.

01

Offline accounts are always available

Upstream hides offline mode and every third-party service for a list of locales until you sign in with Microsoft or switch on developer mode. That check is gone. Pick a username, optionally pin a UUID, and play.

02

Ely.by, two-factor included

Yggdrasil has no field for a one-time code, so services expect it appended to the password after a colon. Upstream surfaced Ely.by's "account protected with two factor auth" as a raw error you could not act on. XMCLF recognises it, asks for the code, and joins the two itself — a password containing a colon is never mistaken for a code.

03

Built-in services survive a bad network

Ely.by and LittleSkin ship with their metadata baked in and are cached to disk on first run. Before, a launch that could not reach their API left the account picker showing a bare hostname with no register link — or nothing at all.

04

It will not update itself into something else

Auto update is off. Upstream's updater resolves releases from the original project, so a fork that kept it would quietly replace itself with X Minecraft Launcher. Releases here are installed by hand, on purpose.

05

Its own data directory

XMCLF stores instances, accounts and assets in %APPDATA%\xmclf, separate from upstream's xmcl. Both launchers can be installed side by side without sharing a folder or fighting over a lock file.

Windows will warn you on first run

The build is not code-signed, so SmartScreen shows “Windows protected your PC”. Choose More info, then Run anyway. Signing needs a certificate that costs a few hundred dollars a year; until there is one, that warning is unavoidable for any small project.

Verify what you downloaded instead. Run Get-FileHash xmclf-1.0.0-win-x64-setup.exe in PowerShell and compare it with 5478edf34686d84ab257afd8a9b9ea1778ae4ad8f1459c12a0deb3e5c364a5b7, or with the .sha256 file attached to the release.
